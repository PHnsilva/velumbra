# Rider–Waite–Smith — rascunho do lote inicial (posições 1–7)

Este lote contém sete resumos originais e sete esboços vetoriais feitos por Codex (assistente de IA) para a issue #38. São rascunhos editoriais: a licença de distribuição do projeto não foi definida, nenhum revisor humano foi indicado e as imagens permanecem em `docs/`, fora de `public/`. Não anunciar nem tratar o lote como aceito ou pronto para sorteio.

## Pesquisa e adaptação

A referência primária consultada foi A. E. Waite, *The Pictorial Key to the Tarot* (1910), em cópia digitalizada: <https://www.willemwitteveen.com/wp-content/uploads/2018/12/The-Pictorial-Key-to-the-Tarot.pdf>. Ela foi usada para conferir a sequência e o vocabulário simbólico da edição RWS. Os resumos foram escritos do zero; nenhum trecho nem imagem do livro foi incorporado. As ilustrações usam cenas e composições próprias para evitar reproduzir elementos característicos das cartas de Pamela Colman Smith.

A sequência editorial deste lote começa pelo Louco, com `numberLabel: "0"`, seguido dos arcanos I a VI. Waite registra que a posição do Louco variou historicamente; esta escolha segue o número zero já usado na amostra RWS do projeto e precisa da revisão editorial do lote.
