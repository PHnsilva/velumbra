São rascunhos editoriais: a licença de distribuição do projeto não foi escolhida, nenhum revisor foi indicado e as imagens não foram copiadas para `public/` nem conectadas ao runtime. As referências orientam conferência de nomes, sequência e vocabulário comum. Os resumos abaixo foram redigidos do zero; nenhum texto ou desenho foi copiado. Elas não concedem licença para reproduzir imagens de terceiros.

- Lenormand.dk, *The Lenormand Deck — All 36 Cards*: <https://lenormand.dk/cards>.
